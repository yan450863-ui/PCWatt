# PC Watt

**看清电脑用了多少电，花了多少钱。**

PC Watt 是一个面向 Windows 的开源功耗与电费查看器。填写自己的人民币电价后，就能查看已记录用电对应的所选时段的估算电费，也能切换 CPU、显卡、外设和其他部件的耗电图表。

本地保存，无账号、无广告，不上传使用记录。界面保持简单，关闭后留在托盘继续记录。

当前版本：**0.3.2（预览版）**。Windows 10 1809+ / Windows 11，x64。安装包已包含 .NET 10，不用额外安装运行环境；Windows 10 和不同硬件仍需更多实机验证。

## 它能做什么

- **把电费放在首页**：小时、日、周、月、年切换，日期栏查看历史和前后时段；图表与费用使用同一范围，历史费用按当时电价计算。
- **看清哪些部件在用电**：整机、CPU、显卡、外设、其他五项切换；图例、波浪分层和悬浮窗统一按 CPU、显卡、外设、其他排列，内存归入主机“其他”。主机自动识别，无需手动校准。
- **顺手看看温度和占用**：显示 CPU / 显卡温度，以及 CPU / 显卡 / 内存占用率；读不到时保持未知。“更多传感器”可查看硬盘温度、风扇转速、CPU/显卡附加温度与读取状态。
- **托盘后台记录**：关闭窗口释放界面，点开重新加载；鼠标悬浮托盘图标查看整机功率和温度。清理硬件库重复历史缓存，已断开来源仅保存一次结束点。
- **四档记录模式**：精细 5 秒、细 10 秒、一般 30 秒、省电 1 分钟，默认一般。
- **按自己的电价算钱**：设置人民币元/度和生效日期，保留电价历史。首次未配置电价时直接定位输入；今日卡片按两天共同记录的相同钟点比较电费，至少 30 分钟且都有人民币电价才显示。
- **外设按需计费**：填写显示器及其他独立供电外设的使用瓦数并启用后，加入总功耗和总电费；外设也能单独查看。
- **看显示器状态**：亮屏、熄屏或调暗；状态读数独立于手动外设估算。
- **备份与恢复**：设置页两个按钮，保存记录、电价与设置到一个 .pcwatt 文件；恢复先校验并确认，重启后替换数据，自动保留恢复前备份。

## 开始使用

1. 在 [Releases](https://github.com/yan450863-ui/PCWatt/releases) 下载 `PCWatt-0.3.2-Setup-win-x64.exe`，双击安装。
2. 打开 PC Watt，在设置里填写自己的电价（元/度）。
3. 等待可用硬件读数并开始记录。需要完全退出时，从右下角托盘菜单选择“退出”。

安装本身不需要管理员权限。默认启用登录自启动和启动时请求完整硬件读取，可分别在设置中关闭；完整硬件读取使用正常 Windows UAC 授权，取消后仍可记录可用项目。

也提供 `PCWatt-0.3.2-win-x64.zip`：解压完整目录后运行 `PCWatt.App.exe`。它同样使用本地用户数据目录，不是数据随 U 盘移动的便携模式。不要只复制 EXE 而丢掉其余文件。

当前安装包未作代码签名，Windows 可能显示“未知发布者”或信誉提示。请认准本仓库 Releases，并使用附件 `SHA256SUMS.txt` 核对下载内容。

## 数值代表什么

**支持的数字电源可优先提供主机总功率，但普通电源的额定瓦数不代表实时耗电。** 软件尝试读取已有数据连接上的电源总功率：交流输入保留为电源遥测，原生直流总输出按 90% 效率估算输入，绝不再叠加 CPU/GPU；不使用缺失分路合成的总量。无可用接口时继续采用组件和通用估算，不安装驱动，也不代表外部墙插功率计或整户账单。

外设默认关闭且没有预填瓦数。在设置填写显示器及其他独立供电外设的实际使用功率，保存并启用后，从下一次采样加入总值。USB 键鼠等已由主机供电，不能重复填写。手动估算按记录时段计费，不自动检测外设开关；外设关闭时需要关闭估算开关。修改设置不重算旧记录，主机不可读时总值保持未知，外设仍能单独查看。

- CPU / 显卡能否读取取决于设备、现有驱动接口与权限。管理员权限不保证读数可用；本版本不安装内核驱动。
- 没有内存功率传感器时，内存采用系统合计 **8 W 通用估算**；占用率是独立数据，不用于换算瓦数。
- 图表显示记录到的有效区间。暂停、休眠或长时间缺失不补零、不用当前功率追算，已记录费用不等于全天完整费用。
- 显示器状态来自 Windows 当前会话，不保证实体电源键或多屏逐台识别；未配置功率时不计费，手动估算不会随状态自动启停。

波浪平滑只用于显示，不创建样本或填补缺失，真实积分结果保持不变。小时默认最近 60 分钟、按分钟汇总；历史小时可以指定日期和小时。日按小时、最近七天按天、自然月按天、自然年按月。未来时间留空；切换历史不影响当前功率卡或后台采样。夏令时的重复小时通过前后导航逐段访问，跳过的小时不可选。

更多传感器只展示当前读数，不保存温度/转速历史，不把它们换算成瓦数。零转速可能是停转或未连接的接口，不能据此推算耗电。硬盘温度并非每台设备都支持。

当前尚不包含 CSV/JSON 导出、历史清除界面或外部功率计接入。备份会包含使用记录，需自行妥善保管；恢复是替换而不是合并，恢复前副本保存在用户数据目录 Recovery 中。

## 数据与隐私

设置、电价、历史记录默认保存到 `%LOCALAPPDATA%\PCWatt`，启动诊断也只写本地。日常运行不要求联网，没有账号系统和遥测上传。升级前请从托盘退出旧版；卸载默认保留历史记录与电价。[隐私说明](docs/PRIVACY.md)

## 开发与许可

技术栈：C#、WPF、.NET 10、MVVM、SQLite；使用 LibreHardwareMonitor 读取可用硬件信息。

```powershell
dotnet restore PCWatt.sln --locked-mode
dotnet build PCWatt.sln -c Release --no-restore
dotnet test PCWatt.sln -c Release --no-build --no-restore
```

- `src/`：App、Core、Infrastructure、Launcher。
- `tests/`：积分、计费、持久化、硬件选择、生命周期与渲染测试。
- `packaging/`：EXE 安装包构建与 GitHub 发布工具。
- `docs/`：使用说明、[轻量优化与备份验证](docs/VALIDATION-LEAN-BACKUP.md)、[图表顺序与设置精简验证](docs/VALIDATION-UI-ORDER.md)、[外设、电源与波浪图验证](docs/VALIDATION-PERIPHERALS-WAVES.md)、[历史与传感器验证](docs/VALIDATION-HISTORY-SENSORS.md)、[开发说明](docs/DEVELOPMENT.md)、[需求](docs/PRODUCT-REQUIREMENTS.md)、[路线](docs/ROADMAP.md)与验证记录。
- `licenses/`：第三方许可证、声明及需附带的模块源码。
- `artifacts/`：本地构建、测试、备份和发布产物，不上传源码仓库。

本地工程入口为根目录 `启动.cmd`；分发安装版使用桌面或开始菜单快捷方式。打包方法见 [packaging/README.md](packaging/README.md)。
