# 轻量优化、备份恢复与使用引导验证

日期：2026-10-28；版本：0.3.2。发行状态见 PROJECT.md。

## 已实现

- 每次硬件更新后清理 LibreHardwareMonitor 未使用的传感器历史缓存，保留当前值和最小/最大值。功耗历史仍由 SQLite 保存，没有增加采样循环。
- 已断开的来源仅写一次空结束点；重连建立新记录边界，避免反复写入失效来源，也不跨断线积分。
- 设置页不随采样事件反复整理图表；回到概览立即刷新。托盘释放界面与前台动效策略保留。
- 暂停、读取中断、过期、无权限和未知功率使用简短提示；真实零功率仍显示 0.0，未知显示破折号。
- 未配置当前有效的人民币电价时，打开窗口直接定位到电价输入，其他设置沿用默认。
- 今日电费卡在原有提示位置显示与昨日的差额，只比较两天共同有效的同一钟点，至少 30 分钟且均有人民币电价。按各自当时电价计算，缺失与来源冲突排除，夏令时切换日不比较。结果在前台缓存 30 秒，电价或日期变化失效，不新增后台任务。
- 设置页新增两个数据按钮。备份包含样本、传感器目录、电价、通知日期与设置；SQLite 在线快照包含已提交 WAL，不直接复制正在写入的数据库。
- 备份按固定条目读取，验证 SHA256、格式版本、数据库完整性及设置。恢复经确认后重启执行，替换原数据，恢复前自动生成普通备份；原子恢复标记在两份文件恢复完成前保留，意外退出时下次启动先回滚。损坏的待恢复文件隔离并继续使用原数据。
