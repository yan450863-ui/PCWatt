# PC Watt 0.2.0 本地预览版

看过去花了多少电费，也能顺手查看硬件状态。

- 电费和图表增加小时、周视图，支持选择历史日期、前后时段和回到现在。
- 历史费用使用当时的电价；未知时段不补零，也不用现在的功率补算过去。
- “更多传感器”集中展示可用的硬盘温度、CPU/显卡更多温度和风扇转速，首页仍保留五个主要部件。
- 原采样循环继续复用，面板只在打开时更新；温度和转速不计入耗电或电费。

本地安装包与 ZIP 已完成验证，当前尚未上传 GitHub。升级前从托盘退出旧版，再运行安装包；设置、电价和历史记录继续使用本机原数据目录。

传感器支持取决于硬件、现有接口和授权；不可读时明确提示。整机功耗仍为估算，不含显示器，也不代表墙插功率计实测。详细测试见 [历史与传感器验证](../VALIDATION-HISTORY-SENSORS.md)。
