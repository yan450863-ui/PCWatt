# PC Watt 0.3.0 本地预览版

- 新增外设功耗设置：填写显示器和其他独立供电外设的使用瓦数，启用后加入总功耗和总电费，也能单独查看外设费用。
- 首页“内存”入口改为“外设”；内存耗电保留并归入“其他”，占用率照常显示。
- 柱图改为分色波浪面积与数据点，支持悬浮查看；缺失处断开，平滑不改变历史计算。
- 优先尝试读取支持的数字电源总功率，没有接口时仍自动采用组件估算。原生直流输出按效率估算输入，不重复叠加 CPU/GPU。

外设默认关闭，不预设瓦数。只填写独立供电设备，USB 键鼠等不要重复计入。手动估算不跟随熄屏自动关闭，外设关闭后需关闭估算开关。

本地安装包已通过验证，Debug / Release 各 282 项测试通过。升级前从托盘退出旧版；设置、电价和历史记录保留。本次尚未上传 GitHub。完整记录见 [验证说明](../VALIDATION-PERIPHERALS-WAVES.md)。
