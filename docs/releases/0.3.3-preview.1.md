# PC Watt 0.3.3-preview.1 · 硬件故障诊断

**看清电脑用了多少电，花了多少钱。**

本版改进 CPU 功率不可读时的说明与排查流程。PC Watt 仍只读取已有硬件接口，不会自动安装驱动或上传诊断信息。

## 下载

- `PCWatt-0.3.3-preview.1-Setup-win-x64.exe`：推荐，双击安装，包含 .NET 10 运行环境。
- `PCWatt-0.3.3-preview.1-win-x64.zip`：完整解压后运行 `PCWatt.App.exe`，请保留全部文件。
- `SHA256SUMS.txt`：核对安装包与 ZIP。
- `PCWatt-0.3.3-preview.1-Readme-zh-CN.txt`：中文安装与使用说明。

适用 Windows 10 1809+ / Windows 11，x64。此版本是公开预览版，非稳定版；安装包没有 Authenticode 代码签名，下载时请核对仓库和 SHA256。

## 主要更新

- 设置页新增硬件检测，分别显示 CPU、显卡及整机状态。
- CPU 读取失败时区分 PawnIO 驱动缺失、服务停止、接口不可用和权限不足；无法查询服务状态时不会猜测驱动缺失。
- 支持手动重新检测并重新初始化硬件会话。探测样本不加入电量统计，旧会话先正常保存，暂停状态保持暂停。
- 可主动复制最小化诊断信息，便于反馈硬件故障；不包含电价、用电历史、用户名或文件路径。
- 驱动问题只提供 PawnIO 官方页面入口。安装由用户自行选择；软件不下载、不安装或更新驱动。
- 原有历史、费用、计费、缺失时段和数据格式规则保持不变。

## 升级说明

安装前从系统托盘完全退出旧版。升级保留已有用户设置、电价和本地记录；卸载也会保留用户数据。CPU 或显卡接口仍受设备、现有驱动及权限影响，管理员权限不保证所有硬件都可读。暂停、休眠和缺失时段不补算。
