# PC Watt 0.3.2 · 历史统计、外设计费与轻量优化

**看清电脑用了多少电，花了多少钱。**

PC Watt 是一款简单、本地优先的 Windows 功耗与电费工具。填写自己的人民币电价，就能查看电脑及已配置外设的估算电费；历史记录全部留在本机，无账号、无广告、不上传数据。

## 相比 0.1.0 的主要更新

- **历史电费更好查**：小时、日、周、月、年五种视图，选择历史日期、前后切换，电费与图表显示同一范围；按当时生效的电价计费。
- **耗电波更直观**：分色波浪面积与数据点，图例、分层和悬浮窗统一按 CPU → 显卡 → 外设 → 其他排列，内存归入其他。缺失时段断开显示，平滑不改变实际积分。
- **显示器等外设可计费**：填写独立供电外设的实际使用瓦数并启用后，加入总功耗与总电费，也能单独查看外设。默认不启用、不预填瓦数，手动输入明确标为估算。
- **支持更多现有传感器**：在“更多传感器”查看可用的硬盘温度、风扇转速和 CPU／显卡附加温度。支持的数字电源会优先尝试读取总功率，普通电源仍使用组件估算。
- **一键备份与恢复**：记录、电价与设置保存到一个 .pcwatt 文件。恢复先校验并确认，重启后替换数据；自动保留恢复前备份，中断时回滚。
- **使用更省心**：首次未配置电价时直接定位输入；功率不可读、过期、暂停和中断都有简短提示，未知不显示为零。
- **电费增加轻量比较**：今日卡片比较两天共同有效的相同钟点，至少 30 分钟且都有人民币电价时才显示差额，数据不足就隐藏。
- **减少后台负担**：清理硬件库未使用的重复历史缓存，已断开来源只保存一次结束点，设置页停止重复查询图表。关闭窗口仍会释放界面，后台只继续监控、保存与托盘功能。

## 升级与计费说明

安装前请从系统托盘完全退出旧版。升级沿用已有设置、电价与历史，卸载也会保留本地数据。恢复备份会替换当前数据，不是合并。

整机功率与电费包含估算，不等于墙插功率计或整户账单。硬件可读性取决于设备、现有接口与权限；默认可请求正常 Windows 管理员授权，取消后继续使用可读项目，授权也不保证能读取。程序不安装内核驱动。

外设手动估算按记录时段计费，**不会随屏幕熄灭自动停算**；关闭外设时请关闭该估算开关。USB 键鼠等由主机供电，不要重复填写。暂停、休眠及缺失时段不补算。
