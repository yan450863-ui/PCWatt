# PC Watt 0.1.0 · 首个公开预览版

**看清电脑用了多少电，花了多少钱。**

PC Watt 是一款简单、本地优先的 Windows 功耗与电费工具。设置自己的人民币电价后，查看已记录用电对应的今日、本月和今年估算费用；需要时再切换 CPU、显卡、内存和其他硬件的耗电图表。

Windows 10 1809+ / Windows 11，x64。安装使用当前用户目录，可选择安装位置，不需要管理员权限。ZIP 版同样在本地用户目录保存数据，不是数据随解压目录移动的便携模式。

## 已有功能

- 首页突出电费，支持今日 / 本月 / 今年切换和按生效日期计价。
- 整机、CPU、显卡、内存、其他五项图表；硬件分色柱、总量折线及精简悬浮卡。
- CPU / 显卡温度、CPU / 显卡 / 内存占用率，以及显示器亮屏状态。
- 托盘记录、登录自启动、暂停 / 恢复、四档采样，默认每 30 秒。
- 关闭窗口释放界面，后台继续记录；所有数据默认仅保存在本机。

## 使用前请了解

整机功率和电费属于**估算**，不等于墙插功率计或整户电费。CPU / 显卡读数取决于硬件、现有接口及权限；默认可请求 Windows 管理员授权，取消后继续使用可用项目，授权也不保证能读取。本程序不安装内核驱动。

内存缺少瓦数接口时采用固定 8 W 通用估算；显示器只有状态、没有可靠瓦数，暂不计费。暂停、休眠及缺失区间不补算。当前版本不提供导出、任意历史日期、备份恢复界面或外部功率计接入。

安装升级前请从托盘完全退出旧版。卸载保留历史记录、电价和设置。当前发布未作代码签名，Windows 可能提示未知发布者或信誉不足；请核对官方仓库和 SHA256。
