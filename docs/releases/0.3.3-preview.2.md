# PC Watt 0.3.3-preview.2 · 界面与可读性更新

本版采用深墨绿侧栏、浅灰工作区和深绿电费卡，增强导航、按钮与图表文字的可读性。默认窗口缩小为 1120×800，保留自由缩放。

## 下载

- `PCWatt-0.3.3-preview.2-Setup-win-x64.exe`：双击安装，包含 .NET 10 运行环境。
- `PCWatt-0.3.3-preview.2-win-x64.zip`：完整解压后运行 `PCWatt.App.exe`。
- `SHA256SUMS.txt`：安装包与 ZIP 的校验值。
- `PCWatt-0.3.3-preview.2-Readme-zh-CN.txt`：中文使用说明。

适用 Windows 10 1809+ / Windows 11，x64。此版本为公开预览版，安装包未作 Authenticode 代码签名。

## 更新内容

- 电费、功率与趋势图的背景层次更加清晰；删除页头副标题及重复说明。
- 导航选中态增加底色、白字和左侧标记；统一按钮、分段、输入框和设置控件的交互状态与键盘焦点。
- 加深图表坐标、图例说明与悬停文字，改善小字对比度。
- 优化紧凑窗口、多显卡选择、历史日期与图表工具栏的布局。
- 默认窗口由 1440×980 调整为 1120×800，最小尺寸维持 960×700。

## 升级与数据

安装前从托盘菜单完全退出旧版。升级继续使用 `%LOCALAPPDATA%\PCWatt` 下的记录、电价和设置；本版不修改数据库结构、计费、采样或历史积分规则。

“今日”在跨越午夜后切换到新一天，不代表历史记录清空；可用日期选择器查看前一天，或切换“本月”查看累计。需要保存副本时，在设置中使用“备份数据”导出 `.pcwatt` 文件。

自编代码采用 MIT；第三方许可与所需模块源码随安装包和 ZIP 提供。
