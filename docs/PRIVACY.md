# 隐私说明

PC Watt 0.1.0 的日常运行不需要账号，不上传功耗、温度、占用率、电价或使用记录，也不要求连接互联网。

软件在本机读取可用的 CPU、显卡等组件功率和温度、系统占用率，以及显示器型号和 Windows 显示状态。功率样本按时间戳和来源保存到本地 SQLite，用于计算电量及估算电费。没有瓦数接口的部件使用明确标注的通用估算，不把未知值当成实测。

默认本地目录为 `%LOCALAPPDATA%\PCWatt`，包括设置、电价和历史记录。启动问题可能写入本地 logs 目录，包含启动时间、程序路径、进程和错误信息，不自动发送。卸载保留这些数据，重新安装可以继续读取。

Windows 用户级自启动只管理本程序对应的 HKCU Run 项；读取更多硬件时使用 Windows 正常 UAC 授权，可取消，也可在设置中关闭。软件不安装内核驱动、不创建系统服务、不控制风扇。

访问 GitHub 下载或反馈问题时，网络访问由浏览器和 GitHub 处理。提交截图或日志前请自行检查其中的路径、硬件型号和其他不想公开的信息。
