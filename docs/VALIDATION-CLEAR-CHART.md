# 五项视图、时间轴与后台资源验证

日期：2026-10-25；Windows 11 x64，.NET SDK 10.0.401。

## 已确认行为

- 首页五项为整机、CPU、显卡、内存、其他。其他合并硬盘、风扇、主板、手动方案其余功率及估计电源损耗；不再提供硬盘的独立首页入口。设备与历史原样保留。
- 删除“记录详情”，图表在默认和最小窗口中占满指标卡下方剩余空间；设置页独立滚动，底部状态栏保持可见。
- 图表使用 CPU 蓝、显卡橙、内存紫、其他青绿；整机柱堆叠后叠加深色总量折线。提高色彩饱和度、柱宽、折线与端点尺寸，纵轴减少不必要留白。灰色仍表示原整机记录无法拆分。
- 横轴固定为完整本地自然日、月、年，各类别共用相同时间范围；柱和悬停均由真实起止时间定位，不再将未结束的小时时段拉成与完整小时相同的宽度。未来时段留空，不创建未来样本、分组或费用。日刻度为 HH:mm，月刻度 MM-dd，年刻度月份，靠近周期末端的重复密集标签省略。月长、闰月和夏令时沿用本地规则。
- 鼠标移动时在图表内立即绘制悬浮卡和区间高亮，离开后关闭，不使用额外定时器或硬件读取。显示区间、度数、有效时段平均功率 W、覆盖率、估算属性、组成及缺失提示。平均功率按已记录电量除以覆盖时长计算，不冒充该时刻瞬时功率。
- “其他”是只读投影，不写入传感器目录或样本表。整机拆分必须通过原样本、方案 ID 和瓦数核对；缺少依据或存在未拆分部分的整个分组，其“其他”保持未知。这个保守规则可能舍弃分组内部分可拆分数据，不将未拆分总量算成其他，也不显示测得零值。原整机账单和颜色总量不变。
- 隐藏或最小化窗口后停止界面时钟，取消未完成的界面查询，释放界面历史、曲线和账单快照，不再投递采样驱动的界面刷新；重新显示后重新加载。采样器和持久化继续工作，保持原单循环。托盘鼠标移动触发的格式化限制为每 250 ms 至多一次；采样事件仍及时更新。
