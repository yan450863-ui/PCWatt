# 分阶段开发与验收

用户先确认第一阶段范围，随后要求改善 UI、增加动态并继续下一步。当前后台提供精细（5 秒）、细（10 秒）、一般（30 秒）、省电（1 分钟），默认一般；电费只提供人民币。第一至第三阶段、真实硬件与自动估算已实现；首页采用简洁的主要部件分类切换，历史日期和五种周期统计已实现，备份恢复界面已实现，CSV/JSON 导出与历史清除仍待开发。产品基线见 [PRODUCT-REQUIREMENTS.md](PRODUCT-REQUIREMENTS.md)，最新验证见 [VALIDATION-SIMPLE-UI.md](VALIDATION-SIMPLE-UI.md)。

## 第一阶段：工程骨架（已完成）

交付四项目解决方案、中文 MVVM 主窗口、简易点状折线图、统一样本模型、来源与估算标记、可注入模拟源、SQLite 原始记录、每日积分、覆盖率与缺失区间、独立费用计算、硬件适配接口、测试和开源文档。

第一阶段交付时仅在窗口内采样。当前关闭后默认托盘记录，具有设置页和用户级自启动；默认 30 秒采样，支持 5/10/30/60 秒。人民币单价默认未配置，费用为未知。

当前已有历史电价规则和真实组件采集；电费采用独立的整机历史账单口径，点击硬件只切换功率和部件耗电图。模拟源仅保留测试用途和已有历史。

## 第二阶段：生命周期与设置基础（已实现并自动化验证）

- 建立独立、持久化的用户设置及迁移机制；各开关分开保存。
- 实现每用户单实例、托盘与关闭行为、自启动当前用户注册项；默认策略按产品规范，设置关闭后立即移除注册项。
- 把唯一采样调度循环从窗口移出；窗口隐藏时停止绘图刷新，采样持续。运行中切换四档频率替换等待策略，不叠加循环。
- 统一取消、暂停、退出、刷新待写数据和释放资源；原始采样按批次/事务写入。
- 为暂停、恢复、休眠、时钟跳变记录明确区间边界；即使短暂停顿也不跨越暂停积分。
- 验收：可替换的自启动配置存储测试、单实例竞争、设置恢复、频率切换无重复调度、暂停与退出 flush、取消无任务泄漏。

本轮同时完成深色仪表盘、渐变面积曲线、末端呼吸光点、数值过渡、悬停读数和动效开关。动效只影响呈现，不参与积分。SQLite 升级到 schema 2，保留旧样本，并随新样本保存有效间隔规则，频率变化不会把历史缺失重新积分。

自启动采用当前用户注册表项；单实例使用按用户隔离的命名互斥量与管道。自动测试不修改真实自启动项；Windows 登录、托盘菜单完整实机操作、关机和实际资源占用仍需发布前实机验收。

## 第三阶段：人民币历史电价与通知（已实现并自动化验证）

- 保存人民币统一电价的生效日期和版本；按积分区间与电价边界分别裁切。首次配置可以选择历史日期，后续仅允许今天或未来的新生效日期；同日冲突、追溯覆盖均拒绝，旧记录保留。
- 界面仅提供人民币，使用“元/度”“元”“度”等中文单位；验证价格范围与小数位，不预设单价，不隐含整户固定月费。为分时电价保留独立策略接口。
- 启动通知与昨日报告独立开关，组合为一条；按本地自然日持久化发送状态，通知失败不影响采样。
- 报告携带覆盖率、未知区间、模拟/估算属性及计价版本；可靠门槛为覆盖率至少 80% 且有效覆盖至少 1 小时，不足时不展示具体耗电和电费。
- 验收：跨午夜/跨电价边界计费、历史规则不被当前改价覆盖、未配置/异常价格、通知合并、同日去重、数据不足、通知不可用。

SQLite 升级到 schema 3，兼容 schema 1/2；旧设置读取迁移为新频率规则。通知通过系统托盘提交，记录每日尝试日期以防重复，系统是否展示仍需实机验收。Debug 与 Release 各 125 项测试通过。

## 第四阶段：历史统计与本地数据管理

- 首页今日/本月/今年整机电费和下方周期图联动已实现：今日按小时、本月按天、今年按月；整机图覆盖全部方案的非重叠有效历史，组件图使用所选来源。空白不补零，显示电量和覆盖率。小时/周视图、历史日期选择和前后导航已实现：小时默认最近 60 分钟，周为所选日期及前六天；所有未完成区间只统计已记录时间。
- 周期图使用平滑波浪与数据点，总量按 CPU/显卡/外设/其他分色面积（内存和硬盘归其他）；经历史方案和原瓦数核对后拆分，无法追溯的旧方案保留未拆分灰色。分色与总量守恒，不修改历史计费。
- 延续柔和曲线、动态尾点和覆盖率设计，分别说明组件、估算和实测口径。
- 校验后备份恢复已实现，含恢复前自动备份与中断回滚。复制报告、CSV/JSON 导出、历史清除与明确二次确认仍待开发；清除默认保留设置和电价。
- 验收：本地时间与夏令时、范围裁切、总计一致性、CSV/JSON 往返、备份恢复失败保持原库、清除范围和设置保留。

## 第五阶段：硬件来源与发布验证（组件采集与可选曲线已提前实现）

- 已接入 LibreHardwareMonitor 0.9.6 的 CPU/GPU 功率传感器；能力检测与读取失败状态独立，无权限/不支持返回未知，不回退为模拟。
- 首页已简化为整机、CPU、显卡、外设、其他五项分类，功率与单条曲线同步切换；同类多个设备使用简短按钮选择。电费固定整机口径，后台采集范围独立于查看，小部件仍计入整机估算。
- 已加入当前 CPU/显卡温度显示，复用现有采样和硬件会话，无读数不估算；显卡核心温度已在本机普通权限验证，管理员 CPU 温度尚未实机验收。
- 已加入托盘悬浮整机功耗/温度，以及应用内 CPU/显卡/内存占用率；复用原采样帧和事件，无新后台计时器。普通权限占用率已实读，系统托盘实际悬浮尚未实机验收。
- 已增加整机/硬件两种视图及 CPU 封装汇总；默认零配置自动估算，内存/磁盘/风扇有瓦数时优先读取，否则明确标记为通用估算。高级校准已删除，自动识别；旧方案继续用于历史还原；外部功率计尚未接入。
- 已改为当前用户无窗口自启动器，并加入本地启动日志；命令重放成功，实际 Windows 登录仍待验收。
- 已升级 schema 4，保存传感器目录及独立历史；沿用旧文件路径，保留模拟记录、设置、电价和通知日期。
- 明确 CPU/GPU/其他组件、整机估算和外部功率计实测的类型、聚合与重叠规则。组件相加不得称为整机实测。
- 暂停/退出释放对象；根据用户后续要求，完整硬件模式默认请求 Windows 管理员授权，可关闭或取消，取消后继续普通权限记录。已实机验证管理员 CPU 读取与正常进程交接；不安装驱动、不绕过 UAC、不增加账号、上传或强制联网。
- 验收：适配器替身测试、初始化失败、单传感器失败、不可用设备、资源释放；Windows 10/11 与常见缩放比例实机测试、采样/隐藏时资源占用测量、许可和发布包检查。

## 0.2.0 传感器扩展（已实现）

- “更多传感器”展示当前硬盘、CPU、显卡等温度及风扇 RPM，逐项显示不可用/授权/过期/暂停状态。
- 复用原硬件更新和唯一采样循环；不新增硬件组驱动、不持久化这些读数，不将温度、转速转换为瓦数。
- 首页仍为五项主要部件，详细状态默认收起；界面隐藏或失焦关闭传感器面板。
- 验证与实机支持边界见 [VALIDATION-HISTORY-SENSORS.md](VALIDATION-HISTORY-SENSORS.md)。

## 0.3.0 外设、电源与波浪图（已实现）

- 外设设置可配置显示器及其他独立供电外设的使用瓦数；默认不启用、不预设瓦数，开启后加入总功耗与总电费，单独查看时展示外设费用。内存归入“其他”，USB 设备不能重复计入。
- 电源遥测优先，原生直流总输出按效率估算输入；没有接口则回退到原组件估算。额定功率、分路合成缺失值不作为主机总功率。
- 分色波浪面积与数据点取代柱图，缺失分段；平滑只影响显示，不改变积分。
- 验证和限制见 [VALIDATION-PERIPHERALS-WAVES.md](VALIDATION-PERIPHERALS-WAVES.md)。

## 后续执行约束

每阶段先核查已有文件和验收条件，再实现并实际构建测试。数据库变更必须有明确版本与迁移，保留用户已有记录。不得把此计划或测试替身描述为已实现的硬件功能。截断的第九节待用户后续补充。
